# Этап 06: Интеграции в enterprise-стек

> ⏳ Черновик. Контент в разработке.

Как WAF встраивается в окружение: балансировщики, CDN, SIEM, сканеры уязвимостей.

## План раздела

- LB/ADC: F5 BIG-IP, Citrix ADC, HAProxy, NGINX Plus, Kemp.
- CDN/Edge: Cloudflare, Akamai, Fastly, AWS CloudFront+WAF, Azure Front Door, GCP Cloud Armor.
- On-prem/аппаратные: F5 ASM/Advanced WAF, Imperva, FortiWeb, Radware, Citrix ADC WAF.
- SIEM/SOC: логи CEF/LEEF/syslog → Splunk, QRadar, Sentinel; correlation rules.
- IDPS, SOAR: автоматическое блокирование по инциденту.
- DAST/SAST: импорт уязвимостей для virtual patching.
