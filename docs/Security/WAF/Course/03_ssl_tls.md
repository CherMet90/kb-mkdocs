# Этап 03: SSL/TLS и WAF

> ⏳ Черновик. Контент в разработке.

TLS как неотъемлемая часть WAF: терминирование, ключи, SNI, mTLS.

## План раздела

- SSL termination (decryption) на WAF vs end-to-end encryption vs SSL bridging.
- Forward secrecy, TLS 1.3, ECDHE — почему нельзя «просто расшифровать».
- Где хранятся приватные ключи: KEK, HSM, KMS.
- SNI-based routing и много сертификатов на одном IP.
- mTLS для API-входа.
- Типичные проблемы при внедрении: изменение TLS и заголовков `X-Forwarded-*`.
