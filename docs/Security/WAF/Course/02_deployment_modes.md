# Этап 02: Режимы развёртывания WAF

> ⏳ Черновик. Контент в разработке.

Ключевой блок для сетевого инженера: где физически и логически стоит WAF и как это влияет на трафик.

## План раздела

- Reverse proxy (inline, L7 proxy) — терминирование TCP, новый запрос к бэкенду.
- Transparent bridge / L2 inline (bump-in-the-wire) — без изменения IP/MAC.
- Out-of-band / sniffing (IDS-режим) — зеркалирование SPAN, только алерты.
- WAF as a Service (cloud/CDN WAF) — переключение DNS на облако.
- Сравнительная таблица: как работает, плюсы, минусы.
- Топологии: где MAC, IP, SSL-сессия, кто терминирует TLS — для каждого режима.
