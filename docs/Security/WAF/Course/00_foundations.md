# Этап 00: Основы — HTTP, TLS и безопасность приложений

> ⏳ Черновик. Контент в разработке.

Фундамент, без которого WAF не понять: протоколы прикладного уровня, TLS и модель веб-безопасности.

## План раздела

- HTTP/1.1, HTTP/2, HTTP/3 (QUIC): структура запроса/ответа, заголовки, методы, статус-коды.
- HTTPS, TLS-хендшейк, SNI, ALPN, сертификаты (x509, цепочки, OCSP stapling).
- TCP/IP аспекты, влияющие на прокси: MSS, time-wait, keepalive.
- Веб-архитектура: reverse proxy, load balancer (L4 vs L7), CDN.
- Cookie, session, JWT, CSRF, CORS, Same-Origin Policy.
- REST, GraphQL, WebSockets, gRPC.
- OWASP Top 10 и OWASP API Security Top 10.
- Bots, scraping, credential stuffing, L7 DDoS.
