# Этап 05: Политики и правила WAF

> ⏳ Черновик. Контент в разработке.

Движок WAF: как формируются правила и модели защиты.

## План раздела

- Signature-based (модель по сигнатурам, как у ModSecurity Core Rule Set).
- Negative model (блокировать плохое) vs Positive model (allowlist) — плюсы/минусы.
- Behavioural / ML-based (Cloudflare, Imperva).
- Learning mode / simulation: только лог, без блокировки (для обкатки).
- Приоритеты и действия: deny, log, rate-limit, challenge, redirect.
- Rate limiting / bot management / CAPTCHA / JS challenge.
- GeoIP- и ASN-блокировки.
- Исключения (exceptions/bypass) для false positives — управление техдолгом.
